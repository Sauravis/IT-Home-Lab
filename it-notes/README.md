# 🧠 IT Knowledge Notes

This section contains basic IT concepts learned during training and opposition study (TAI), applied to real-world IT support scenarios.

---

## 🧠 Topics covered

- Active Directory basics  
- DNS and DHCP concepts  
- Windows vs Linux administration  
- Basic IT infrastructure (CPD)  
- Backup concepts (RPO / RTO)  

---

## 📌 Examples

- DNS helps translate domain names into IP addresses  
- DHCP automatically assigns IP addresses to devices  
- Active Directory manages users and permissions in Windows environments  
- Linux is widely used for servers and system administration tasks  
- Backups ensure data recovery in case of system failure
